## 1. Introduction
This project is an Excel-based analysis of 10 selected stocks from the NIFTY-50 index for the year 2025. The dashboard tracks annual performance, sector-wise trends, and trading volumes. It is designed to identify market leaders, laggards, and overall market sentiment using historical price data.

## 2. Skills Used
* **Microsoft Excel:** The entire project was built using Excel.
* **Slicers:** Used for interactive filtering (e.g., selecting "Bank", "IT", or "FMCG" to filter the charts).
* **Conditional Formatting:** Applied to the "Annual_return%" column (Green for positive, Red for negative) to create a heatmap effect.
* **Pivot Tables & Aggregation:** Used to calculate total traded volumes and average returns.
* **Data Visualization:** Created Combo Charts, Bar Charts, and Sparklines/Line charts.
* **KPI Cards:** Created dynamic cards to display key metrics like 52-Week High/Low and Market Averages.

## 3. About Charts
The dashboard includes the following specific visualizations:
* **Performance Ranking Bar Chart:** Arranges stocks from highest return to lowest return to visualize the leaderboard.
* **Sector & Stock Return Comparison (Combo Chart):** Groups stocks by their industry (Bank, FMCG, IT, Oil & Gas, Telecom) to compare individual performance against their sector.
* **Monthly Price Trend (Line Chart):** plots the "Closing value" from Jan to Dec to show price volatility over time.
* **Heatmap Table:** A data table showing exact return percentages with color coding for quick readability.
